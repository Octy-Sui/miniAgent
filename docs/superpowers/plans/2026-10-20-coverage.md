# Layered coverage implementation plan

**Goal:** Add pytest-cov and coverage development dependencies and a root `coverage.py` CLI producing isolated UT/IT/SIT/E2E and union reports under `coverage/<run-id>/`.

**Architecture:** Run each selected pytest directory in a separate process, collect branch-enabled process shards, normalize installed-package paths, seed the complete production source inventory, and merge data before generating independent line/branch metrics. Reports include module metrics, pytest outcomes, source identity and collection limitations.

**Constraints:** Preserve existing test reorganization and unrelated edits; no README changes or commits. Root script must not shadow the coverage library. Keep crash-test semantics; disclose SIGKILL and uninstrumented container limitations.
